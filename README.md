# Airbnb Market Analysis & Pricing Insights | Python

## Project Overview
Developed an exploratory data analysis (EDA) project using Airbnb listing data to analyze pricing trends, customer preferences, room type popularity, neighbourhood demand, and revenue opportunities. The project focuses on uncovering actionable business insights through data visualization and analytical techniques using Python.

---

## Key Features
- Performed data cleaning, transformation, and exploratory data analysis using Pandas
- Analyzed customer preferences based on room types, pricing, and neighbourhood groups
- Created price segmentation categories for budget, mid-range, and luxury listings
- Built multiple visualizations to analyze market demand, pricing distribution, and competition
- Identified top-performing neighbourhoods based on reviews and revenue potential
- Analyzed the relationship between listing availability and pricing patterns
- Generated business insights to support pricing optimization and market strategy decisions

---

## Analysis Modules

### Room Type & Customer Preference Analysis
- Room type popularity across neighbourhood groups
- Customer preference analysis based on listing categories

### Pricing & Market Analysis
- Price range distribution across neighbourhoods
- Average pricing analysis by room type and location
- Budget vs luxury listing competition analysis

### Demand & Revenue Analysis
- Top neighbourhoods based on customer reviews
- Market saturation analysis by neighbourhood
- Revenue potential analysis using listing and stay information

### Availability Analysis
- Relationship between availability and pricing trends
- Listing availability distribution analysis
